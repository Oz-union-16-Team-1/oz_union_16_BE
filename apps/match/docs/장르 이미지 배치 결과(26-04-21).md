## 1. 검증 목적
- 장르 이미지 배치가 IGDB 조회 후 Redis에 8개 장르 이미지 맵을 정상 저장하는지 확인

## 2. 사전 이슈 및 조치
- 이슈: 초기 실행 시 후보가 전부 0건
- 원인:
  1) 장르 이미지 배치에서 내부 장르 매핑과 IGDB 실제 장르 매핑 혼용
  2) category가 `None`인 데이터가 많아 category 필터에서 전량 탈락
- 조치:
  1) 배치 전용 매핑 `API_TO_IGDB_IMAGE_GENRE_MAP` 분리 적용
  2) category/status null-safe 필터 적용 (`None`이면 통과, 값이 있을 때만 검증)
  3) 후보 배정 충돌 완화를 위해 `GENRE_PRIORITY`를 후보 수 적은 장르 우선으로 재정렬

  - `updated_count: 8`

## 5. Redis 저장 검증
- key: `match:genre:image_map:v1`
- 저장 구조:
  - `{ genre_id: { game_id, image_url, rating, rating_count } }`
- 저장된 장르 키: `1,2,3,4,5,6,7,8` (8개 확인)
- image_url 형식: `https://.../t_1080p/...` 확인
- game_id 중복: 없음
- 우선순위 반영 순서 확인:
  - `8 → 5 → 1 → 6 → 7 → 4 → 3 → 2`

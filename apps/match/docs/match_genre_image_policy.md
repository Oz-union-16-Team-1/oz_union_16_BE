# MATCH 장르 대표 이미지 운영 정책

## 목적
장르 선택 화면(8개 카드)에 사용할 대표 이미지를 안정적으로 제공

## 적용 범위
- 본 문서는 장르 이미지 **배치/캐시 정책**을 정의한다.

## 배치 주기
- 월 1회 실행

## 데이터 소스
- 장르별 후보 게임을 기준으로 대표 이미지를 선정한다.
- 장르 매핑은 `API_TO_IGDB_GENRE_MAP(1~8 -> 1~14)`을 따른다.
- 배정 우선순위는 `GENRE_PRIORITY`를 따른다.

## 배정 정책
- 중복 절대 금지 (`used_game_ids`)
- 우선순위가 높은 장르부터 선점
- 후보 게임이 없으면 배치를 실패 처리한다.

## 캐시 저장 정책
- Redis key: `match:genre:image_map:v1`
- 저장 방식: **TTL 없이 overwrite**
- 교체 방식: 8개 장르 결과 계산 후 map 단위로 1회 교체(원자적 교체)

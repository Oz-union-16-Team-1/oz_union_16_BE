# MATCH 장르 대표 이미지 운영 정책

## 목적
장르 선택 화면(8개 카드)에 사용할 대표 이미지를 안정적으로 제공

## 적용 범위
- 본 문서는 장르 이미지 배치 및 캐시 정책을 정의한다.

## 배치 주기
- 일 1회 실행

## 데이터 소스
- 장르별 후보 게임을 기준으로 대표 이미지를 선정한다.
- 장르 매핑은 `API_TO_IGDB_GENRE_MAP (1~8 -> 1~14)`을 따른다.
- 배정 우선순위는 `GENRE_PRIORITY`를 따른다.

## 후보 필터 기준
- 게임 타입:
  - 정식 메인게임 / 리메이크 / 리마스터만 포함
- 출시 상태:
  - 정식 출시 게임만 포함
- 플랫폼:
  - PC 포함 게임만 포함
- 품질:
  - 평가 수 50 이상
  - 평점 70 이상
- 데이터 완결성:
  - 커버 이미지 존재 필수
- 출시일:
  - 최대 조회 범위(기본 10년) 이내

## 배정 정책
- 중복 절대 금지 (`used_game_ids`)
- 우선순위가 높은 장르부터 선점
- **컷오프 완화 정책**:
  - 30일 ~ 12개월(월 단위)
  - 2년 ~ 10년(연 단위)
- 각 단계마다 배정을 시도하고, 실패 시 다음 단계로 완화한다.

## 실패 시 fallback
- 완화 단계를 모두 시도해도 배정 실패 시:
  - Redis 기존 이미지 맵을 재사용한다.
- 기존 캐시도 없으면 배치를 실패 처리한다.

## 캐시 저장 정책
- Redis key: `match:genre:image_map:v1`
- 저장 방식: **TTL 없이 overwrite**
- 교체 방식: 8개 장르 결과 계산 후 map 단위로 1회 교체(원자적 교체)
